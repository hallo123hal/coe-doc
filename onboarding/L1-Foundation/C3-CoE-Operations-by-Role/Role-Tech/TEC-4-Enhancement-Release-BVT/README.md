# TEC-4. Enhancement, release and BVT

> Nguồn: page 2482897340.

Module cuối của Tech track: việc Tech làm quanh một enhancement — đọc tài liệu ENH, bật cấu hình sau release, làm BVT PIC. Kết thúc bằng **role track exit**: Tech final assessment + incident drill. Role track exit không phải L1 certification (L1 theo từng service qua T4, T5 — CM-11). Vòng đời ENH, N-IRP và 8 luật BVT đã học ở G6.1 nên ở đây chỉ học phần Tech tự làm.
