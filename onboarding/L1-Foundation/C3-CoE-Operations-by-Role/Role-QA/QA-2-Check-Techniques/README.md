# QA-2. Check techniques

> Nguồn: page 2482929961.

Module thực hành cho QA mới: kiểm promotion bằng promotion simulator, test user group và Special Price Report; kiểm product, price, stock trên Backoffice và storefront; kiểm EPP, Shop App, AEM; rồi dựng evidence pack và ghi kết quả trên Jira. Mọi bài chạy trên Backoffice staging và frontend staging; chưa có quyền staging thì mỗi bài có bản giấy với ảnh chụp do facilitator chuẩn bị.

| Session | Thời lượng | Mục tiêu chính |
|---|---|---|
| [QA-2.1 Checking promotions](QA-2.1-Checking-Promotions.md) | 90' | Đọc rule promotion trong Backoffice và so 6 giá trị với internal check |
| [QA-2.2 Checking products, prices and stock](QA-2.2-Checking-Products-Prices-Stock.md) | 75' | Dự đoán CTA khách thấy từ trạng thái SKU, xác nhận bằng PDP và ATC API |
| [QA-2.3 Checking special channels](QA-2.3-Checking-Special-Channels.md) | 60' | Đọc cấu hình EPP site và dự đoán khách EPP thấy gì về login, quota, giá |
| [QA-2.4 Negative testing, evidence and QA return](QA-2.4-Negative-Testing-Evidence-Return.md) | 70' | Thiết kế bộ test positive/negative/exploratory cho promotion chưa gặp |
| **Tổng** | **295 phút (~4.9h)** | |
